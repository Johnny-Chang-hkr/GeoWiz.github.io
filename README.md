# GeoWiz

GeoWiz is a responsive, no-install geography quiz for curious minds. Pick a
continent, choose a round length and difficulty, then match cities to countries.

## Features

- City quizzes across all six inhabited continents, including North and South
  America.
- Quick (5), regular (10), and extended (15) rounds.
- Three difficulty settings, with 3, 4, or 5 answer choices.
- Optional 15-second timer for each question.
- One letter-and-length hint per question; a correct answer after a hint is
  worth no points.
- Answer feedback, round accuracy, progress, and streak tracking.
- Saved best score, best streak, and completed quiz count in browser storage.
- Light and dark themes, keyboard shortcuts, reduced-motion support, and
  responsive layouts.

## Play

Open `index.html` in a browser, or visit the
[GeoWiz website](https://Johnny-Chang-hkr.github.io/GeoWiz.github.io/).
No build step or package installation is required.

## Keyboard shortcuts

- Press `1`–`5` to choose an answer.
- Press `H` to use a hint.
- Press `Enter` to continue after answering.

Personal statistics and theme preferences are stored locally in the browser.
